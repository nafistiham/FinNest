# Judges' demo bundle

`FinNest-judges-protected.zip` holds two Android demo APKs and a guide for the competition judges.
The zip is password-protected; the team shares the password with the judges separately.

| APK | Behaviour check |
|---|---|
| `FinNest-A-behaviour-check-on.apk` | On (recommended) |
| `FinNest-B-behaviour-check-off.apk` | Off (backup) |

The APKs are demo builds: signed with a development key and carrying one App Check debug token
that is revoked after judging. See `HOW-TO-USE-FINNEST.md` inside the zip.
